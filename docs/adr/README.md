# Architecture Decision Records

Each important decision gets one short file: context, decision, consequences. A decision is never edited after it's accepted; a new ADR replaces it and the old one is marked **Superseded**.

## Template

```md
# ADR NNNN: Title

- **Status:** Proposed | Accepted | Superseded by NNNN
- **Date:** YYYY-MM-DD
- **Issue:** #N

## Context
## Decision
## Consequences
```
